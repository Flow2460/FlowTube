# Security Policy

## Supported Versions

Only the latest release of FlowTube receives security updates and bug fixes. Please ensure you are running the most recent version downloaded from the official [FlowTube itch.io page](https://fk-software.itch.io/flowtube).

| Version | Supported          |
| ------- | ------------------ |
| 1.5     | :white_check_mark: |
| < 1.5   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in FlowTube, please **do not** open a public GitHub issue. Instead, report it privately so it can be investigated and patched before public disclosure.

### How to Report
* **Email:** Send a detailed report to **Florian.Knecht.Software@outlook.com** with the subject line `[Security] FlowTube Vulnerability Report`.
* **What to Include:**
  * A clear description of the issue and potential impact.
  * Step-by-step instructions to reproduce the vulnerability.
  * Your FlowTube version (found in `VERSION.txt`) and Windows version.

### What to Expect
* **Initial Response:** You can expect an acknowledgment of your report within **3–5 business days**.
* **Updates & Resolution:** If the vulnerability is confirmed, I will keep you updated on the progress and release a patched version on itch.io as soon as possible. If the report is declined (e.g., expected behavior or third-party dependency issue outside FlowTube's scope), I will reply with an explanation.
