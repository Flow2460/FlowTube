# Contributing to FlowTube

Thank you for your interest in **FlowTube**! Contributions that help improve documentation, usability, and bug tracking are always welcome.

---

## What You Can Contribute

Because FlowTube is distributed as a closed-source **freeware** Windows application (with public documentation, release notes, and issue tracking hosted in this repository), contributions are currently focused on:

- **Bug Reports & Feature Suggestions:** Reporting reproducible issues, edge cases, or ideas for future updates.
- **Documentation Improvements:** Fixing typos, clarifying setup instructions, or improving guides in `README.md`.
- **Translations & Localization:** Helping translate documentation or suggesting UI text improvements.

> **Note on Security Issues:** Please do **not** open a public issue for security vulnerabilities. Follow the instructions in [`SECURITY.md`](SECURITY.md) instead.

---

## How to Submit a Bug Report or Feature Request

1. Check the [existing issues](https://github.com) to make sure your topic hasn't already been reported.
2. Open a **New Issue** and include:
   - **FlowTube version** (found in `VERSION.txt` or the app window)
   - **Windows version** and selected **browser** (Chrome, Brave, Firefox, Edge, or Safari)
   - **Steps to reproduce** the issue clearly
   - Relevant excerpts from your log files (`AppDataDir/logs/*Logs*.txt`), removing any personal file paths if needed

---

## Pull Request Workflow

1. **Fork** the [`Flow2460/FlowTube`](https://github.com) repository.
2. Create a new branch from `main` for your changes (e.g., `docs/fix-typo` or `docs/update-faq`).
3. Keep your changes focused, clear, and consistent with the existing formatting.
4. Open a **Pull Request** targeting the `main` branch and briefly explain what you changed and why.

*All pull requests require maintainer review and approval before being merged into `main`.*
